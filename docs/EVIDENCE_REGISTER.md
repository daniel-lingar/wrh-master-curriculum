# WRH Claim-Level Evidence Register — Phase 1 (Starter)

**Purpose:** A claim-level evidence register for material claims in the WRH Master Curriculum, following the 7-field schema of `docs/EVIDENCE_BASE.md` exactly. This is a Phase 1 starter register; it is **not** a completed, independently reviewed evidence record, and it does **not** endorse or approve any claim for delivery.

**Honesty standard (binding):**
- WRH is WITHDRAWN from delivery. No claim in this register is validated by any completed, independently reviewed study.
- A supporting source is listed ONLY where the source was actually inspected during this phase (inspection recorded per entry). No uninspected source is cited.
- For each claim the register distinguishes: (a) evidence supporting the GENERAL CONCEPT, (b) evidence supporting the EXACT WORDING and its applicability to participants, (c) evidence evaluating WRH ITSELF. General trauma research is never used to imply WRH has been validated.
- Where evidence is absent, the register states exactly: **not verified in this phase.**
- Independent reviewer fields are PENDING — no names, credentials, decisions, or approvals have been recorded.

**Schema note (ambiguity recorded):** `docs/EVIDENCE_BASE.md` defines exactly 7 fields per material claim. The schema does not define an explicit "evidence status" field or a "blocking review item" flag; both are recorded below in addition to the 7 fields, applied literally and uniformly, so schema ambiguity is not resolved by dropping either.

**Source locator convention:** Line references below refer to immutable baseline commit `e6d350e4300d2fa10a10db15b44a56e3d770eb9c`, before Phase 1 warning insertions. Each primary claim links to its baseline passage. Quoted source statements and review interpretations are distinct. No external evidence was added or clinically verified in this follow-up.

**Field order per entry (schema fields 1–7, in order):**
1. Exact claim + module/session
2. Supporting primary or authoritative source, publication date, link or identifier
3. Applicable population and setting
4. Strengths, limitations, and uncertainty
5. Claim type (educational / clinical / legal / operational / marketing)
6. Independent reviewer: name, qualification, review date, decision, required edits
7. Revision version that implemented the decision

Entries flagged **BLOCKING** must be resolved by independent clinical review before any delivery of that material.
