IDs `WRH-D-ER-001` onward are assigned **in topic order, D-01 first through D-08, then cross-cutting claims for the file set they span**. Within a topic: lesson claims first, then facilitator-guide claims (D-05–D-08 set, where the extraction is in that order), then workbook claims — in each case following the extraction file's own order within that topic. Every entry carries its source extraction number, so the mapping is reversible. ## Reading rules applied to every entry

- **Field 2, uninvestigated claims:** written exactly as `None inspected in this phase.` No source has been invented. Where a Phase 4 dossier family genuinely investigated the claim's family, the dossier section, its verdict, and its inspection limits are recorded instead, faithfully as given in the extraction file.
- **Field 4, uninvestigated claims:** the uncertainty is that no evidence has been inspected; "uninvestigated–unresolved" is not a finding that a claim is false, and the dossier's silence is not support.
- **Field 5:** mapped from the extraction claim types (DEF/CAU/OUT/INS/OTH; mechanism/causal/outcome/other). Default is `educational`. A non-educational classification is used only where the entry is plainly a facilitator/operational instruction, scoring rule, participation rule, or package statement, and is explained in one phrase in the cell. No claim in this register was classified clinical, legal, or marketing.
- **Field 6, every entry:** `PENDING — no reviewer assigned; no decision recorded.` No reviewer or decision has been invented.
- **Field 7:** the Phase 5 implemented change (before → after), credited to "Phase 5 development draft (unapproved)", where the extraction file records one — including authorship in a file newly authored in Phase 5 — otherwise exactly `No change implemented; claim retained as extracted.`
