# WRH Core Curriculum (v2.0)

## Governing Instructional Rule

> **Show it → Name it → Explain it → Separate it → Interrupt it → Practice it → Carry it.**

## Standard Constraints

This participant-facing curriculum follows a clear, plain-language standard. It targets plain language at approximately an **8th-grade reading level** (not yet independently tested), avoids clinical jargon, and requires **no forced disclosure**. The lessons are **non-diagnostic**: participants do not need to accept a label or agree with a framework to recognize a pattern and decide what to do next. Each lesson preserves **stoic agency**, separating a person’s first reaction from the choices and responsibilities that follow.

## Lesson Collections in This Directory

This directory holds **two parallel lesson collections**, and their development relationship is recorded in [CURRICULUM_MAP.md](../../CURRICULUM_MAP.md):

1. **Four-track collection** — the eight capitalized files `Lesson_01_…` through `Lesson_08_…` (e.g., `Lesson_01_What_Is_a_Survival_Response.md`). Each file contains the same lesson authored in **four settings tracks**: Corrections, Reentry, Veteran, and Workplace. These are settings-specific translations of the core lesson content.
2. **Lowercase collection** — the sixteen files `lesson-01-…` through `lesson-16-…` (e.g., `lesson-01-what-is-a-survival-response.md`). These are the standalone participant-facing lessons.

The table above reflects the **lowercase collection's** Lesson 1–8 sequence. The four-track sequence is different: Lesson 2 is Safety vs. Familiarity, Lesson 4 is Impact vs. Intention, and Lessons 5–8 are Perception vs. Fact, Control vs. Influence, Accountability vs. Blame, and Ownership vs. Defense. Do not pair these collections by number. The workbooks (1–4 and 5–8) and facilitator guides (1–4 and 5–8) use the four-track sequence's titles and together form the Lane D development package's companions (Phase 5); the package is an **UNAPPROVED DEVELOPMENT DRAFT — NOT FOR DELIVERY**, and this association is a development direction, not approval or clinical review.

> **Development direction recorded:** Lane D (eight four-track topics) is the working package under owner delegation; Lane C (sixteen lowercase lessons) is preserved as a deferred expansion. D-01–D-08 are package IDs, not Lane C pairings. No extension beyond eight Lane D topics or delivery authority is implied. See the root curriculum map and [Phase 5 manifest](../PHASE5_PACKAGE_MANIFEST.md).

## Lane D application order

For D-01–D-08, present the selected track scenario, then use **Recognize → Name → Explain → Separate → Interrupt → Practice → Carry It**. “Show it” is the introductory scenario, not a replacement for Recognize. Accountability Check, Boundary Check, Next Action, and Carry-Forward are supporting lesson sections. Workbooks use their fifteen numbered sections; guide discussion redirects are supporting prompts, not a second lesson sequence. This development convention does not resequence Lane C.
