# WRH Core Curriculum (v2.0)

## Governing Instructional Rule

> **Show it → Name it → Explain it → Separate it → Interrupt it → Practice it → Carry it.**

## Standard Constraints

This participant-facing curriculum follows a clear, plain-language standard. It is written at an **8th-grade reading level**, uses **zero clinical jargon**, and requires **no forced disclosure**. The lessons are **non-diagnostic**: participants do not need to accept a label or agree with a framework to recognize a pattern and decide what to do next. Each lesson preserves **stoic agency**, separating a person’s first reaction from the choices and responsibilities that follow.

## Lesson Collections in This Directory

This directory holds **two parallel lesson collections**, and their relationship is **currently undocumented**:

1. **Four-track collection** — the eight capitalized files `Lesson_01_…` through `Lesson_08_…` (e.g., `Lesson_01_What_Is_a_Survival_Response.md`). Each file contains the same lesson authored in **four settings tracks**: Corrections, Reentry, Veteran, and Workplace. These are settings-specific translations of the core lesson content.
2. **Lowercase collection** — the sixteen files `lesson-01-…` through `lesson-16-…` (e.g., `lesson-01-what-is-a-survival-response.md`). These are the standalone participant-facing lessons.

The table above reflects the **lowercase collection's** Lesson 1–8 sequence; the first eight lessons of that sequence correspond by title to the eight four-track files, but the repository does not state how (or whether) the track-specific content relates to the lowercase lessons — e.g., whether the tracks replace, supplement, or are superseded by them, or which collection is canonical.

> **Owner decision needed:** define and document the relationship between the four-track collection (`Lesson_01..08`) and the lowercase sixteen-lesson collection (`lesson-01..16`) — which is canonical, how the settings tracks map to the standalone lessons, and what Lesson 9–16 of the four-track set would look like (they do not exist). Until that decision is recorded, do not assume one collection supersedes the other.
