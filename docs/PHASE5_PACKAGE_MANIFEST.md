## Development conventions

Present the selected track scenario, then apply **Recognize → Name → Explain → Separate → Interrupt → Practice → Carry It**. Accountability Check, Boundary Check, Next Action and Carry-Forward support those steps. Workbooks retain fifteen numbered sections. Guide redirect prompts support discussion and do not replace the lesson sequence.

The eight topics and source filenames are retained. Package IDs D-01–D-08 distinguish Lane D from other numbering systems. Each track keeps its Carry It/Carry-Forward; workbook §13 is the separately labeled shared practice statement. A guide anchor is a teaching example, not a replacement track statement. Workbook checkboxes and guide self-reflection descriptors use different presentations; neither is a validated scale or a facilitator-scored outcome.

The first workbook uses shared fictional practice illustrations; the Lessons 1–4 guide also maps each track scenario. The second workbook and the expanded Lessons 5–8 guide map all four track scenarios. Shared guide illustrations are labeled optional and do not replace the selected track scenario.
